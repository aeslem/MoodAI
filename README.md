
The Problem:
   Many people struggle to understand their emotional state while being in a stressful situation and doing what is actually right gets harder to manage. Plus, emotional state can depend on multiple factors like stress, sleep quality, being in crowd for too long, etc.
   The goal of this project is to create a rule-based artificial intelligence system that asks the user planned questions, analyzes their answers, calculates a mood score and givws personalized advice according to their result. The program should also get user input, reject invalid inputs and give randomized advice for a more interactive experience. 
Problem Solution Explanation:
This program,
1- Welcomes the user.
2- Asks mood-related questions with scores from 0 to 5.
3- Checks the input so users cannot enter invalid values.
4- Calculates the average mood score.
5- Finds the user’s mood category.
6- Gives random advice according to the mood result.
7- Allows the user to requestt another advice.
The project is developed in Python using variables, loops, lists, and randomization. To make the interaction feel more dynamic, the program uses Python’s “random.choice() function to display different advice messages each time.
